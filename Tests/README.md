# 字幕回归验证

需要源码仓库，在仓库根目录运行（发布包仅携带本文档，不含测试源码）：

```powershell
dotnet run --project Tests/Regression.csproj
```

需要 .NET 8 或更新版本的 SDK。测试链接实际的 JSONC、广播、声线查询、本地化和日志限频源码，使用替身隔离 Unity、Harmony、设置和文件路径；不启动游戏、不修改游戏目录，不需要下载测试框架。覆盖转义及注释、广播开关组合、广播序列重置、缺失/损坏声线缓存和手动重载、日志限频窗口、翻译格式回退、界面键及占位符一致性，并解析现有语言及预设文件。

这些检查不能验证 Unity 对象生命周期、实际画面或 Fika 联机播放。游戏内回归应包括：

1. 主菜单发送预览字幕，再进入藏身处/战局；字幕、弹幕、3D 气泡均正常。
2. 连续进出两次战局、反复开关战斗界面；没有重复管理器、丢字幕或已销毁对象异常。
3. 关闭字幕总开关但保留广播字幕开关，实验室广播不显示字幕；弹幕同样验证。
4. 切换语言或重载资源后，广播组合从新序列开始；新建或修复声线文件后重载可读取。
5. Fika 主客机分别测试自己、队友和 AI 发言，检查重复显示及频道过滤。
6. 切换中文/英文/俄文，检查预设名称、操作提示、导出报告及诊断状态；自定义文件名和配置键保留原文。
7. 高密度语音时关闭调试开关，确认没有逐事件距离日志；打开详细日志后确认限频。资源页不随语音重新扫描，事件页最多每 0.25 秒刷新一次。
8. 设置较低的字幕显示容量和 3D 角色数量，确认被拒绝的事件报告为未接收，弹幕排队报告为已排队；清理管理器时报告管理器未就绪。

本轮不修改或补全翻译文本。
