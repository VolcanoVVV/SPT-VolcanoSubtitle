# 界面本地化维护

`locales/<lang>/UI.jsonc` 包含 `Common`、`Categories` 和 `Settings`。中文、英文、俄文共用同一套键；可复制一份目录添加新语言。

- 只翻译值，保持键、配置节名、配置项原文及标识不变。
- `Common` 用于按钮、提示、预览、诊断、错误及报告；`Settings` 提供每项的 `Name` 和 `Desc`。
- `{0}`、`{1}` 等占位符必须与中文保持一致，可调整它们在句子中的位置。
- `Enum.*` 和 `Preset.*` 只改变显示名，不改变配置中保存的枚举或预设文件名。自定义预设未提供译名时显示原始名称。
- JSON 字符串中的引号、反斜杠、换行分别用 `\"`、`\\`、`\n` 表示；支持 `//` 和 `/* ... */` 注释。
- 修改文件后通过设置中的“重新加载本地化资源”更新缓存。格式化文本损坏时会回退默认文本并限频警告。

新增代码显示文本通过 `I18n.Text` 或 `I18n.Format` 查询，并同步维护三个界面文件。运行 `dotnet run --project Tests/Regression.csproj` 检查键、格式占位符和解析。

配置键、路径、游戏对象名、VoiceKey、Trigger、NetId、日志技术前缀和异常堆栈保留原始标识。语言选择列表显示语言自称，玩家名及字体名保持其原名。

本轮只维护界面文本，角色台词及其缺字/缺译由后续翻译工作单独处理。`Default_Voice.jsonc`、`voices/` 和广播正文不属于本轮翻译修改范围。
