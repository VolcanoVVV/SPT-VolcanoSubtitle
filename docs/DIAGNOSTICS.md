# 诊断与日志

## 事件报告

启用开发者工具或实时语音事件日志后，内存中最多保留最近 200 条语音事件。可通过设置中的诊断按钮查看和复制；无须开启详细控制台日志即可使用面板。

| 状态 | 含义 |
| --- | --- |
| 已接收 / ACCEPTED | 字幕行或 3D 气泡已创建；之后仍可能被优先级抢占或随场景清理 |
| 已排队 / QUEUED | 弹幕已进入队列，等待车道；不表示已经在屏幕上出现 |
| 已过滤 / FILTER | 频道关闭、距离、台词规则、感染者开关/冷却或语音去重 |
| 未接收 / DROP | 管理器未就绪、字幕容量/优先级、弹幕层、说话者或 3D 锚点/数量限制 |
| 错误 / ERROR | 投递抛出异常，查看相应日志；其他频道仍继续尝试 |

报告包含资源匹配来源、字幕行数、弹幕等待数量、3D 角色数及限频跳过的日志数。计数按当前进程累计；清空事件不会重置日志抑制计数。资源来源中的 VoiceKey、Trigger、NetId 和文件名保持原值。

资源页在进入该页、再次点击资源检查或切换/重载语言时扫描。语音事件不会反复触发资源文件读取。资源解析通过不能证明翻译完整或与音频逐句一致。

## 日志控制

- 实时语音事件日志、弹幕详细日志和广播调试日志默认关闭，分别由设置控制。
- 开启实时事件日志后，事件元数据按类别最多约每 0.2 秒一条，频道投递汇总最多每 0.5 秒一条；距离过滤最多每 2 秒一条。
- 弹幕详细日志和去重详情按类别约每秒最多一条；广播详情按类别约每 0.5 秒最多一条。
- 缺失台词警告最多每 30 秒一条，常见播放/字体异常按类别最多每 10 秒一条。不同类别独立限频，首条立即输出。
- 导出保留结束汇总，逐剪辑成功及失败日志限频。日志限频不改变字幕过滤、排队和播放规则。

因此控制台日志用于定位问题，不是完整语音事件流水；诊断面板保留最近的处理结果。日志技术前缀、对象名及异常堆栈保留原文，界面和报告说明按所选语言显示。

日志通常位于游戏目录下 `BepInEx/LogOutput.log`。反馈时提供 SPT/插件/Fika 版本、单机或主客机身份、复现步骤、当前语言、诊断报告及相关错误附近的日志。报告可能含玩家昵称和本地路径，分享前可自行删去这些内容。
